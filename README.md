# Altan Yildirim — Portfolio Website

A responsive personal portfolio for presenting my experience, skills and public software projects.

## Live site

**https://altan-y.github.io/**

## Highlights

- responsive navy-and-gold visual system;
- accessible semantic HTML and keyboard navigation;
- mobile navigation and scroll-based section highlighting;
- lightweight reveal interactions with reduced-motion support;
- real project visuals loaded from the corresponding public repositories;
- automatic deployment through GitHub Pages.

## Privacy

The portfolio intentionally excludes employer names, internal links, credentials, production data and confidential records. Public projects are independently rewritten demonstrations using fictional data.
